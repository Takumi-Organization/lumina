# Fuentes empaquetadas

- **Outfit Variable** (The Outfit Project Authors): títulos (peso 200-300, espaciado ancho). SIL Open Font License 1.1: `OFL-Outfit.txt`.
- **JetBrains Mono** Regular y Medium (JetBrains): datos y etiquetas. SIL Open Font License 1.1: `OFL-JetBrainsMono.txt`.

Procedencia y verificación (2026-11-22):

- Outfit: el fichero es idéntico byte a byte (mismo SHA-256, `fc7287273e66929776e2ba54f144fe699080bec29f61bf649d70d871468aeade`) al `Outfit[wght].ttf` del repositorio google/fonts (`ofl/outfit`).
- JetBrains Mono: son copias sin modificar de los ficheros de otro proyecto del autor (checkmate); el SHA-256 coincide con esos ficheros. **Copia no verificada contra upstream**: el `JetBrainsMono-Regular.ttf` actual de la rama principal de JetBrains/JetBrainsMono tiene un hash distinto (probablemente otra versión), y no se ha comprobado cuál es la oficial exacta.
